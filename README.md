# About
Учебный проект проверки изменения файла index.html

## Как работает
1. Пользователь меняет файл index.html.
2. Изменения коммитятся и пушатся в main ветку.
3. GitHub Actions определяет изменения.
4. Workfow деплоит сайт в GitHub Pages.

## Технологии
- Git
- GitHub
- GitHub Actions
- YAML
- GitHub Pages
